## 使い方の想定
- 「スコア大会(イベント)」に紐づく**イベント名（表示専用＝自由追加タグの候補）**。フィルタチップ（`docs/tags.json`）には入れず、カード上に自動採色で出す想定。
- 火/光/闇/風/水 の属性違い、難/易・A/B/C・前半/後半・総合 は同一イベントの派生。タグは基本「イベント名」単位、派生は〔 〕で併記。
- Tier A/B は動画タイトルに出やすい実用候補、Tier C は旧仕様・難易度分割・テスト等（**参考として残置**）。

## 分類ロジックとの関係（メモ）
- 「○○限定」形式は `scripts/collect.py` の `EVENT_RE` が従来どおり自動抽出する。
- それ以外のイベント名（周年・特訓・コラボ・季節 等）は **`data/event_tags.json` の辞書に載せた分を自動タグ化**（2026-07-22 実装済み）。2026-10-09 以降は、スコア大会(イベント)と判定された動画にだけ付ける（辞書の一致だけでは週末→イベントにしない。ただし回数の直後が辞書の語のとき（「第2回 コンボブレイクスコアタ」等）はイベントの開催回なので回数にせず、イベントになる。2026-10-14〜）。運用手順は [README.md](../README.md) の「イベント名辞書を更新する」を参照。
- このリストのうち**辞書に採用済みなのは Tier A/B の一部**。ボス属性シリーズや Tier C 等は未採用（辞書に追記すれば有効化される）。
- 月間スコア大会は、2026-10-09 からフィルタ用タグ「スコア大会(月間)」として自動判定する（イベント名タグではない）。
