# スコア大会(イベント) 自由追加タグ候補リスト

出典: ゲーム内「過去のスコアタランキング（イベントタブ）」スクリーンショット87枚（2026-07-22撮影・`_local/スコア大会（イベント）名称参考用/`, ページ1/6〜6/6）を OCR → 重複排除・分類したもの。ページ順は概ね新しい順（1/6=直近, 6/6=最古）。

> **固有名詞（特にカタカナ）は OCR 誤読が残り得る。タグ確定は本人の目視確認を正とする。** 末尾「OCR要確認」参照。

## 使い方の想定
- 「スコア大会(イベント)」に紐づく**イベント名（表示専用＝自由追加タグの候補）**。フィルタチップ（`docs/tags.json`）には入れず、カード上に自動採色で出す想定。
- 火/光/闇/風/水 の属性違い、難/易・A/B/C・前半/後半・総合 は同一イベントの派生。タグは基本「イベント名」単位、派生は〔 〕で併記。
- Tier A/B は動画タイトルに出やすい実用候補、Tier C は旧仕様・難易度分割・テスト等（**参考として残置**）。

## 分類ロジックとの関係（メモ）
- 現状 `scripts/collect.py` は「○○限定」形式のみ自動抽出（`EVENT_RE`）。上記の多く（周年・特訓・コラボ・ボス属性シリーズ）は「限定」を含まないため**現状では自動タグ化されない**。
- 自動分類へ組み込む場合の設計方針は別途検討（イベント名辞書の外部データ化＋ reclassify 反映）。
